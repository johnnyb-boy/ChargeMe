# **ChargeMe**
## Une simple application pour forcé la charge de la calculatrice.

### Que fait ChargeMe?
**ChargeMe** Affiche rien du tout (sauf "La calculatrice est allumé") pour permettre à celle-ci de chargé sans ce mettre en veille.

### Pourquoi utiliser ChargeMe?
Cette application est faite pour les **Calculatrices Lycéenne Numworks** qui sont touché par un problème qui empèche l'appareil de chargé lorsqu'elle est étainte.


Cette application additionnel a été faite et compilé en C et en utilisent seulement la librairie ```<eadk.h>``` officiel par Numworks / Epsilon.

### Comment l'installer?
Télécharger ```ChargeMe_FR.nwa``` sur votre appareil pour ensuite le traférer à votre calculatrice en utilisent **[l'installeur d'application additionnel officiel de Numworks](https://my.numworks.com/apps)** (Un navigateur **Chromium (Chrome, Brave, Opera, ect...)** est requis pour cette action.) après sa, Lancé le depuis votre calculatrice et *voila*
